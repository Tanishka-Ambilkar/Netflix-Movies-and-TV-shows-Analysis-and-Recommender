# Netflix Movies and TV Shows Analysis and Recommender

## Project Overview

This project focuses on analyzing Netflix movies and TV shows using Python. It explores different aspects of Netflix content through data analysis and visualization. It also provides a recommendation system that helps users find movies and TV shows based on their preferences.

## Objectives

- Analyze Netflix movies and TV shows.
- Explore content based on genres, countries, release years, and ratings.
- Understand trends in Netflix content over time.
- Identify popular movies and shows using IMDb ratings.
- Recommend movies and TV shows according to user preferences.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- BeautifulSoup
- Jupyter Notebook / Google Colab

## Datasets Used

The project uses two CSV datasets:

1. `netflix_titles.csv` – Contains information about Netflix movies and TV shows.
2. `titles.csv` – Contains additional title information and IMDb ratings for popularity analysis and recommendations.

## Key Features

### Data Analysis

1. Dataset summary & missing values
2. Movie vs TV Show count
3. Top 10 genres
4. Top countries
5. Release-year trend
6. Content ratings
7. Additions over time
8. Average IMDb rating + distribution
9. Highest-rated movies & shows
10. Most popular movies & shows
11. Top 10 by genre
12. Popular titles from a country
13. Recommend me something
14. Wikipedia summary (web scraping)

### Recommendation System

Users can get movie and TV show recommendations by selecting preferences such as:

- Genre
- Release year range
- Country
- Minimum IMDb rating
- Content rating
- Actor, actress, or director

## Project Structure

- `Netflix_Mini_Project.ipynb` – Main notebook containing the Python code, analysis, visualizations, and recommendation system.
- `netflix_titles.csv` – Netflix dataset.
- `titles.csv` – Additional IMDb-related dataset.

## How to Run the Project

1. Download or clone this GitHub repository.
2. Open Google Colab.
3. Upload the notebook and both CSV files.
4. Make sure the CSV filenames match those used in the code.
5. Run the notebook cells sequentially.

## Conclusion

This project combines data analysis, visualization, web scraping, and a preference-based recommendation system to explore Netflix content and help users discover movies and TV shows according to their interests.
